# 🔥 Portfólio — Bombeiro Profissional

> Portfolio profissional desenvolvido com HTML puro + Tailwind CSS, com identidade visual **"Duty & Discipline"** — focada em seriedade, confiança e excelência técnica.

---

## 📋 Sobre o Projeto

Site de portfólio para um **Bombeiro Profissional** com mais de 10 anos de experiência em combate a incêndios, resgate e prevenção. O layout apresenta a trajetória, os serviços oferecidos, missões de destaque e canais de contato profissional.

## 🗂️ Seções

| Seção | Descrição |
|---|---|
| **Hero** | Apresentação principal com chamada para ação |
| **Sobre Mim** | Trajetória profissional com linha do tempo |
| **Serviços** | 6 áreas de atuação técnica |
| **Projetos** | Missões de destaque, ações comunitárias e certificações |
| **Depoimentos** | Reconhecimento de pares e instituições |
| **Contato** | Formulário + informações de contato direto |

---

## 🛠️ Tecnologias

- **HTML5** semântico
- **Tailwind CSS** via CDN (com configuração de tema customizado)
- **Google Fonts** — Work Sans & Inter
- **Material Symbols** — ícones do Google
- Design system próprio: paleta `primary` vermelha, `secondary` âmbar e `tertiary` azul petróleo

---

## 🎨 Identidade Visual

## 🚀 Como Usar

Não há dependências ou processo de build. Basta abrir o arquivo diretamente no navegador:

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/portfolio-bombeiro-profissional.git

# Abra o arquivo no navegador
start index.html   # Windows
open index.html    # macOS
```

Ou simplesmente faça o deploy estático em:

- **GitHub Pages** — `Settings → Pages → Deploy from branch`
- **Vercel / Netlify** — arraste a pasta para o dashboard
